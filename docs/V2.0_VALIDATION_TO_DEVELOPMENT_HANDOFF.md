# V2.0 游戏验证部门 → 核心开发组移交纪要

## 验证部门专业席位
验证总监、足球规则专家、游戏系统专家、数值/概率专家、QA自动化专家、iOS/Safari专家、数据完整性专家、UX/HCI专家、无障碍专家、性能专家、内容/合规专家。

> 本项目使用的是岗位化专家角色，不虚构现实中的具体名人已实际参加。

## P0/P1问题排序与裁决
1. **P0 发布标识漂移**：后台版本升级而首页仍显示旧版。结论：建立单一 BUILD_CONFIG，V2.0所有关键可见入口统一。
2. **P0 世界杯重复入账风险**：恢复或重复回调可能重复累计。结论：保留 matchId 幂等门。
3. **P1 移动端导航过载**：首页顶部入口过多、横向滚动认知负担高。结论：主导航收敛为指挥中心/球队/比赛/世界杯/更多。
4. **P1 首页缺乏当前任务感**：旧首页首先展示宣传语和配置，不告诉玩家“下一步做什么”。结论：重构Match Command指挥中心。
5. **P1 比赛信息层级不足**：比分、动态时间、阶段、实况需更强视觉主次。结论：强化中央记分牌、时钟和LIVE层。
6. **P1 验证与开发混在一起**：结论：验证部独立发现/复验，开发组复现/修改；不允许自批自验。
7. **P2 旧版可见字符串散落**：结论：全包扫描并清理V1.8/V1.9当前版本标识，历史记录除外。

## 各核心组落实
- 产品/UI组：Match Command主界面重构、导航收敛。
- 比赛引擎组：保持V1.8动态时间与Effect解释，强化记分牌层级。
- 赛事组：保留matchId幂等和世界杯连续链路。
- 数据组：Schema 24保持不变，版本单一事实源。
- QA组：新增发布标识一致性扫描。
- 数值组：本版不改核心胜率公式，避免借UI升级引入平衡漂移。
