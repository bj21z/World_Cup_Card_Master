# V1.7.0 部署与回滚

## 升级前

1. 导出当前存档备份。
2. 保留V1.7 RC4完整程序包。
3. 记录当前Cloudflare Pages部署版本。

## 部署

1. 全量上传V1.7.0程序包内全部文件，不做局部覆盖。
2. 等待托管平台构建完成。
3. 清理Cloudflare缓存或触发新部署。
4. iPhone Safari关闭旧标签并清理该站点数据。
5. 重新打开后核对顶部、页脚、欢迎窗口和版本历史均为V1.7.0 / Schema 23。
6. 验证世界杯存档、比赛恢复和一场快速比赛。

## 回滚

1. 停止继续写入新比赛数据。
2. 将站点全量恢复为V1.7 RC4。
3. 清理站点缓存。
4. 导入升级前存档备份。

V1.7.0与RC4同为Schema 23，原则上可以直接回滚，但仍以备份恢复为最稳妥方式。
