# 游戏验证部门（独立验证线）

## 组织原则
验证部门独立于核心开发组。专家为岗位化专业席位，不冒充现实世界具体个人已参与本项目。

## 11个专业席位
验证总监、足球规则、游戏系统、数值概率、QA自动化、iOS/Safari、数据完整性、UX/HCI、无障碍、性能、内容/合规。

## 分工接口
- 验证部：发现、复现、证据、分级、排序、复验。
- 比赛引擎组：时钟、事件、技能、结算。
- 赛事系统组：世界杯、榜单、赛后报告、幂等。
- 数据组：Schema、存档、Event/Effect Ledger。
- 前端体验组：同屏、浮层、触控、信息层级。
- 数值组：概率、封顶、平衡；未经专项批准不改核心胜率公式。
- 发布组：P0/P1清零后才可进入候选版。

## 缺陷等级
P0 数据/流程阻断；P1 事实或核心体验错误；P2 明显体验问题；P3 轻微视觉/文案；P4 建议。
