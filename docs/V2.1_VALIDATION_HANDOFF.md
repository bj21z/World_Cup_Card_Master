# V2.1 验证部门 → 核心开发组闭环
- P1：比赛时间虽然动态，但玩家缺少“时间如何影响决策”的直接入口 → 比赛/UX组 → 新增临场决策条。
- P1：技能/组合数值存在，但玩家容易误认为显示值会再次叠加 → 数值/UX组 → 明示“已计入本回合质量”。
- P1：耐久门禁仍采用固定每回合+6分钟，与正式动态时钟验证模型不一致 → QA/比赛引擎组 → 改为目标时间+jitter+最小推进。
- P2：比赛阶段概念存在于导演逻辑，但未形成玩家可见的决策语言 → 产品/比赛组 → 开局试探、中段争夺、胜负转折、末段决胜。
- 冻结：核心胜率公式、球员基础能力、世界杯晋级、经济系统、Schema 24。
