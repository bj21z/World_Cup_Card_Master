# V1.8 Alpha 2 · Live Match

## 版本定位
本版是基于 V1.7.0 Match Director 稳定母版的 Alpha 工程升级，重点解决用户反馈的“比赛时间不清楚、事件不清楚、技能加成看不到”。

## 核心变化
1. 动态比赛时钟：比赛页面持续显示足球时间和比赛阶段；底层仍为回合驱动，不会因玩家阅读自动推进。
2. 实况事件流：最近事件在比赛主界面持续更新，普通解围和普通扑救不再占据阻断浮层。
3. 效果可见化：球员技能、组合协同、士气、临场波动从真实结算对象读取并展示。
4. 一次点击解释：新增“为何形成这个结果？”入口，提供本回合真实数值来源。
5. Event/Effect Ledger：新增比赛 ID、事件 ID、事件账本与效果账本，为后续完整因果链和一致性审计打基础。
6. 赛后故事和时间轴：赛后报告中可回看 V1.8 关键事件与完整事件账本。
7. Schema 24：从旧存档增量迁移，并保存升级前长期资产快照。

## 保持不变
- V1.7.0 球员基础数据、球队基础强度、世界杯晋级规则保持不变。
- 原比赛进球判定、门将扑救核心公式未因 V1.8 UI 表达升级而重新调参。
- 模拟商城仍不产生真实交易，核心玩法无付费战力加成。

## Alpha限制
- 当前 V1.8 Event/Effect 体系属于第一阶段适配层，尚未将所有旧比赛内部微小 Effect 全部结构化。
- 比赛时间为回合映射的足球时间，不是现实秒表式实时模拟。
- 本版本必须继续真机验证 Safari 生命周期、世界杯长流程与旧存档迁移。
