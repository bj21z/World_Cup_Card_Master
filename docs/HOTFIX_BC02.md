# V1.3.1-BC02 下一回合按钮专项修复

## 问题
在iPhone Safari中，比赛开始后“生成下一回合”可能表现为点击无反馈。原因包含：单一onclick绑定缺少触摸兜底；生成异常没有用户可见提示；战术区在按钮上方生成但页面不自动定位，容易被误判为按钮无效。

## 修复
- click + touchend双通道（带防重复触发）。
- 生成中禁用按钮并显示旋转状态。
- 数据完整性检查与可见错误提示。
- 自动滚动到战术选择区并写入比赛日志。
- 战术按钮明确使用type=button。
- 错误写入Beta测试日志。
- 存档升级至Schema 17，旧存档自动迁移。

## 回归重点
快速比赛、世界杯比赛、连续15回合、智能托管、退出后重开、iPhone Safari触摸操作。
