# 项目会议决议落实对照

| 会议决议 | V1.2落实位置 |
|---|---|
| 玩家关键回合必须有决策 | 比赛中心八种战术选择 |
| 阵容必须可编辑 | 国家队管理：首发与替补互换 |
| 加入队长和定位球主罚者 | 国家队管理选择器 |
| 加入换人和体能 | 比赛换人弹窗、体能条、最多5换 |
| 技能不能只是随机加分 | 场景、时间、能力和上限共同控制 |
| 组合技能应可预览 | 国家队管理连携预览 |
| 结果必须可解释 | 每回合概率解释卡 |
| 进球改成两阶段 | 先形成射门，再进行门将扑救判定 |
| 赛后成长反馈 | 赛后统计、金币、经验与继承说明 |
| 数据与逻辑分离 | lineup/match/tournament/growth/storage模块 |
| 存档必须兼容 | Schema 12迁移 |
| 数值需批量模拟 | 数据实验室100—5000场模拟 |
