# V1.8 Alpha 2 部署与回滚

## 部署
1. 先备份当前 V1.7.0 全目录。
2. 全量上传 V1.8 Alpha 2 文件，不建议局部覆盖。
3. 清除 Cloudflare Pages / 浏览器旧缓存后重新加载。
4. 首次加载会将存档迁移至 Schema 24，并在 `backups` 中建立升级前关键资产快照。
5. 首次进入后检查顶部版本应为 `V1.8 Alpha 2 · Live Match`、`Schema 24`。

## 回滚
- 程序回滚：恢复 V1.7.0 完整目录。
- 数据回滚：Schema 24 数据包含新字段；若必须回到旧版本，优先使用升级前备份/外部导出的 V1.7 存档，而不是让旧代码直接覆盖 Schema 24 数据。

## 缓存刷新
- iPhone Safari：关闭旧标签页后重新进入；必要时清除该站点网站数据。
- Cloudflare：部署新构建后确认构建时间，再强制刷新。
