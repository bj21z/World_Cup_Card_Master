# 临时专项会议：项目进展综合评审暨BC02故障处置会

性质：不改变既有主会议顺序的临时专项会议（Special Review）。
触发原因：真机预检发现“生成下一回合”按钮无反馈，属于核心比赛闭环风险。

## 会议目标
1. 修复核心回合按钮及同类交互风险。
2. 综合盘点现阶段优势、不足与风险。
3. 明确封测前的收口方案和责任人。

## 11位核心负责人意见
- 制作人：核心创新成立，但核心闭环按钮故障必须零容忍；BC02修复后才能继续封测。
- 项目经理：版本路线清晰，但功能增长快于真机回归；新增“关键路径回归门禁”。
- 主策划：战术三牌、组合技能、世界杯征途差异鲜明；新手对“生成牌阵→选战术”仍需更强引导。
- 技术总监：模块化与存档迁移是优势；事件绑定、错误边界和移动端可观测性不足，BC02补齐第一层防线。
- 美术总监：视觉风格统一、卡牌辨识度较好；战术反馈位置不够显眼，需自动定位与层级强化。
- 数值策划：已有矩阵和预警工具；完整逐回合、技能、门将、换人数据仍不足，不能宣称最终平衡。
- AI工程师：规则AI可解释且不读取付费状态；AI战术日志和重复决策检测仍需强化。
- 测试经理：静态检查完善，但真机关键路径覆盖不足；建立每次候选包必须执行的九项点击回归。
- 运营负责人：免费任务循环已形成；任务不应推动玩家绕过核心体验，封测期减少干扰性任务。
- 市场负责人：产品卖点明确；尚无真实留存与推荐数据，市场规模判断仍属待验证假设。
- 商业化负责人：公平商业化边界清晰；当前不接真实支付是正确决定，模拟商城不得干扰首场比赛。

## 法务列席意见
继续标注非商业测试原型；不真实交易、不博彩、不使用未经授权内容收费；外部封测前补齐测试与隐私说明。

## 综合优势
1. 独特的1—3人战术牌阵与组合技能。
2. 比赛、世界杯、成长、任务、数据反馈形成闭环。
3. 模块化工程、存档迁移和测试工具基础较好。
4. 商业化与战力隔离原则明确。

## 综合不足
1. 真机关键路径回归滞后于功能开发。
2. 新手信息量和页面入口偏多。
3. 比赛演出与操作反馈仍为功能型Beta水准。
4. 完整数值平衡、真机兼容和外部玩家数据不足。
5. 48队中只有部分球队使用精细球员卡。

## 最终决议
- 立即发布BC02专项修复包，BC01停止继续投放。
- 主会议序号不变，本次记为“第十一场会议后的临时专项会议A”。
- BC02必须通过关键路径回归后，恢复5—10台真机预检。
- 未完成真机预检前，不进入20人外部封测。
- 后续每次候选版增加“核心按钮可点击、牌阵生成、战术结算、下一回合、智能托管、换人、赛后结算、世界杯续赛、存档恢复”九项门禁。

## 下一次会议准备
真机预检记录、BC02错误日志、连续15回合测试、三场小组赛存档、设备兼容表、S1/S2问题清单。
