# V3.1 真实名单数据说明

## 覆盖
- 2026 FIFA World Cup：48支参赛队。
- 每队26人，合计1,248名球员。
- 当前世界杯选择范围内不再使用“球队模拟”占位卡组。

## 来源策略
1. FIFA：2026-06-02确认48支最终名单、1,248名球员，为赛事名单权威基线。
2. MLSsoccer《2026 FIFA World Cup: All Squads》：用于48队按位置完整名单交叉整理。
3. 个别伤病替换再核验：
   - Austria：Christoph Baumgartner退出后由Dejan Ljubičić替换；Stefan Posch在赛事阵容。
   - Jordan：Ibrahim Sabra退出后由Mohammad Taha替换。
   - Egypt：最终名单包含Mohamed Abdelmonem。

## 重要边界
姓名、球队归属与官方位置组属于真实名单数据。
游戏中的overall以及速度/射门/传球/盘带/防守/身体属于产品自己的游戏模型评分，并不是FIFA官方评分。
