# V1.4 RC2 发布说明

## 修改文件
- index.html：新增版本历史入口、页面和RC2标识。
- css/style.css：新增版本时间轴样式。
- data/betaReleaseConfig.js：构建号更新为V1.4-RC2。
- README.md、VERSION_NOTES.md：更新版本说明。

## 新增文件
- data/versionHistory.js
- js/versionHistoryUI.js
- docs/MEETING_AGENDA_CORE_GAMEPLAY_INNOVATION.md
- docs/V1.4_RC2_CHANGELOG_AND_RELEASE.md

## 删除文件
无。

## 保持不变
比赛引擎、球员数据、战术与阵型系数、技能概率、世界杯规则、金币与训练价格、存档Schema 21。

## 部署
必须全量替换RC1。部署后进入“更多功能 → 版本历史”，确认显示V1.4 RC2及此前版本。

## 回滚
可直接回滚到V1.4 RC1；因Schema未变化，不需要清除存档。
