# 世界杯·绿茵牌阵 V1.1 战术三牌版

## 运行方式
1. 解压本压缩包。
2. 直接打开 `index.html` 即可运行。
3. iPhone 推荐上传到 GitHub + Cloudflare Pages，也可以用 Code App / Code Play 本地预览。
4. 本版本不依赖服务器、不依赖外部 CDN、不需要安装依赖。

## V1.1 核心升级
- 从 V1.0 的固定双卡对峙，升级为“战术三牌引擎”。
- 每回合随机进入 8 类比赛场景：中路推进、边路突破、禁区终结、快速反击、高空轰炸、定位球、后场出球、门前危机。
- 双方每回合随机出 1–3 张牌，支持 1v1、2v2、3v3、1v2、2v3、3v1 等局部攻防。
- 按场景使用不同能力权重，结合位置、阵型、士气、体能、状态波动计算牌阵值。
- 新增组合技能系统：国家队连携、位置连携、战术连携、绝境总攻等。
- 新增世界杯征途模式：48 队、12 小组、小组赛、最好第三名、32 强淘汰赛、点球大战、冠军结算。
- 继续保留球员经验、金币、训练强化、本地存档。

## 数据口径
- V1.1 继承 V1.0 的 8 支精细球队和 88 张球员卡。
- 48 队世界杯征途结构已内置；暂未精细录入的球队使用球队强度和模拟卡运行完整赛制。
- 球员能力为游戏化评分，不是 FIFA、EA SPORTS FC、Opta 或其他商业数据库官方评分。
- 后续版本可继续把更多球队替换成完整真实球员卡。

## 建议玩法
1. 先在“大厅”选择两队，体验快速对战。
2. 在“比赛中心”逐回合翻牌，观察战术场景、组合技能和进球概率。
3. 开启“世界杯征途”，从小组赛一路打到淘汰赛。
4. 用比赛金币到“训练中心”强化球员，下一场继续继承成长。

## 已知限制
- V1.1 是策略引擎升级版，不是完整 1248 名球员数据库终版。
- 暂无真实球员照片、音效、联网更新、在线对战。
- 淘汰赛对阵采用游戏化种子模拟，后续可改成完整官方晋级路径。
- 其他球队模拟卡用于跑通赛制，不声称已完成全部球员真实姓名精细录入。
