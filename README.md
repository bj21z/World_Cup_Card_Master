# 绿茵牌阵：世界杯征途 V1.4.0「赛场焕新版」

这是V1.4四个Sprint与RC阶段完成整合后的正式开发版本，定位为**非官方、非商业、单机网页开发版**。

## 核心内容

- 随机1—3人动态牌阵、战术选择、技能和组合技能；
- 世界杯小组赛、淘汰赛、加时和点球征途；
- 阵容、换人、体能、成长与赛后报告；
- 比赛状态机、自动恢复、移动端防重复操作；
- 进球、神扑、绝杀和球星技能分级演出；
- AI、换人、数值、体能和经济诊断实验室；
- 内容来源、雷达指标和授权状态治理；
- 游戏内完整版本历史中心。

## 部署

必须全量替换旧版文件。部署后清理站点缓存，并确认页面显示：

`V1.4.0 · Schema 22`

RC2与V1.4.0均使用Schema 22，正常情况下无需清除旧存档。升级前仍建议在“封测中心”创建本机备份。

本项目不代表FIFA或任何官方机构；球员评分为游戏化评分；未接入真实支付；正式商业发行前必须完成赛事名称、球员姓名与肖像、队徽、球衣、奖杯和数据来源等授权审查。
