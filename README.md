# 世界杯·绿茵牌阵 V2.0

## 运行方式
直接打开 `index.html` 即可。iPhone 可在“文件”App中解压后，用支持HTML预览的编辑器打开；电脑可用 Safari、Chrome、Edge。

## V2.0核心玩法
- 仍然是卡牌足球游戏，不是摇杆动作游戏。
- 8支国家队、88名真实球员卡及六维雷达图。
- 球会名称、风格、球迷、声望、球场/青训/医疗设施。
- 4种阵型、4种进攻战术、4种防守战术、队长与定位球主罚。
- 11回合翻牌比赛、技能触发、战术加成、士气、体能、高光剧情。
- 球探招募、重复卡转经验、专项训练、全队训练。
- 7轮冠军征程与积分记录。
- 所有成长和经营数据均使用浏览器本地存档。

## 数据说明
球员姓名和国家队归属来自V1.0数据基线；能力值为公开表现基础上的游戏化设计，并非KONAMI、EA或其他商业游戏官方评分。
