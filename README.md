# 世界杯·绿茵牌阵 V1.0

## 运行方式
1. 解压程序包。
2. 直接打开 `index.html`。
3. iPhone 推荐上传到 GitHub + Cloudflare Pages，也可用 Code App / Code Play 本地预览。

## V1.0 核心内容
- 8 支国家队：西班牙、阿根廷、法国、英格兰、巴西、葡萄牙、德国、挪威。
- 每队 11 名首发，共 88 张真实世界杯参赛球员卡。
- 6 维雷达图：速度、射门、传球、盘带、防守、身体。
- 世界级球星专属技能。
- 11 回合翻牌对决、技能触发、特殊剧情、士气与进球判定。
- 比赛金币、经验值、永久训练强化、本地存档。
- 手机端响应式布局，无需服务器、无需安装依赖。

## 数据口径
球员身份参考 2026 世界杯公开阵容与赛事统计。卡面能力值是为游戏平衡制作的综合评分，不是 FIFA、EA Sports FC 或其他商业数据库的官方数值。

## 已知限制
- 第一版暂收录 8 队，不是全部 48 队。
- 暂无联网更新、球员照片、音效、转会市场、在线多人对战。
- 比赛模拟定位为轻策略卡牌玩法，不是现实比赛预测工具。

## 推荐后续版本
V1.1：扩展 16 队、阵型编辑、替补换人、每日任务、音效。
V2.0：48 队完整数据库、赛事模式、球员羁绊、卡包与生涯赛季。
