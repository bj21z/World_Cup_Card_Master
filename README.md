# 绿茵牌阵：世界杯征途 V1.2 Alpha+

## 运行方式

直接打开 `index.html` 即可运行。推荐使用 iPhone Safari、Chrome、Edge 或通过 Cloudflare Pages/GitHub Pages 部署。无需服务器、数据库或安装依赖。

## 本版定位

V1.2 Alpha+「战术指挥官版」是根据项目立项会、产品定位会、核心玩法与玩家体验会、技术方案评审会、美术与交互评审会、Alpha评审会形成的决议进行的一次全量升级。

## 核心功能

- 1—3名球员随机局部攻防
- 玩家每回合选择战术
- 阵型、首发、替补、队长、定位球主罚者管理
- 单场最多5次换人
- 体能、士气、技能、组合技能与阵型影响
- 射门形成与门将扑救两阶段判定
- 每回合概率解释与“为什么赢”
- 48队、12组世界杯征途框架
- 小组积分、最好第三名、淘汰赛、加时与点球
- 球员经验、定向训练与永久成长
- 赛后控球、射门、射正与奖励报告
- 本地存档版本迁移
- 100/1000/5000场自动模拟实验室

## 数据口径

当前继承V1.1的8支精细球队、88名球员卡；其余赛事球队采用球队强度与模拟卡运行完整赛制。能力值为游戏化评分，不是FIFA、EA或其他机构官方评分。

## 已知限制

- 尚未完成外部真实玩家样本测试
- 尚未完成所有iOS/Android机型兼容测试
- 尚未接入在线账号、云存档或多人对战
- 真实球员照片、队徽、赛事标识未加入，避免授权风险
- 48队全部真实名单和精细能力仍需后续逐队补齐
