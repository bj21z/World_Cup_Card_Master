# 当前构建：V1.7.0 · Match Director 正式版

《绿茵牌阵：世界杯征途》V1.7.0是比赛导演系统首个正式发布版，以V1.7 RC4完整源码为唯一基线封装。

## 正式版核心

- 动态牌阵博弈2.0：四种基础战术、软克制、二阶段决策、AI渐进学习与战术欺骗。
- Match Director 1.0：均势、压制、反击窗口、铁桶阵、背水一战、球星时刻六种比赛状态。
- AI局势响应：AI仅使用公开比赛信息，不读取玩家尚未确认的选择。
- 世界杯连续征程：比赛、赛后报告、赛事故事、榜单和下一场形成闭环。
- 一屏比赛与非阻断事件层：普通解围和扑救仅进入时间轴，重要事件采用短暂轻提示。
- 存档、恢复和Safari生命周期防重复结算。
- 50—500场联合耐久门禁与游戏内最终验收中心。

## 版本与存档

- 版本：V1.7.0
- 代号：Match Director
- Schema：23
- 从V1.7 RC4升级不需要清除存档，部署前建议导出备份。

## 部署

全量替换旧版本文件，刷新站点缓存和Safari网站数据，再核对顶部、页脚和版本历史均显示V1.7.0 / Schema 23。

本项目为非官方、非商业、单机网页开发版，不含真实支付；球员评分与比赛结果均为游戏化模拟。

## V1.8 Alpha 2 · Live Match
本版本基于 V1.7.0 Match Director 完整母版升级。比赛中心新增动态足球时间、LIVE 实况事件流、真实技能/组合加成胶囊、“为何形成这个结果？”解释链，以及赛后 V1.8 比赛故事和 Event 时间轴。存档升级到 Schema 24，并在首次迁移时保存升级前关键长期资产快照。

Alpha 2 不改变 V1.7.0 的核心进球/扑救数值公式；本轮首先解决“比赛时间看不清、事件过程不清、技能加成看不到”的用户反馈。
